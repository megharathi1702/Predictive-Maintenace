# ⚡ Electrical Equipment Maintenance – ML Based Predictive System

This project uses Machine Learning to predict potential failures in electrical equipment based on sensor data such as temperature, current, voltage, and vibration. 
The goal is to enable **predictive maintenance** aligned with **Industry 4.0** principles, reducing unexpected breakdowns, cost, and downtime.

---

## 🧠 Project Objectives

- Predict failure of electrical machines using supervised learning
- Minimize unscheduled downtime and maintenance cost
- Improve safety and reliability of electrical systems
- Demonstrate a real-time Industry 4.0 application in maintenance

---

## 🛠️ Technologies Used

- **Python**
- **Pandas**, **NumPy** – Data manipulation  
- **Matplotlib**, **Seaborn** – Data visualization  
- **Scikit-learn** – ML modeling  
- **Decision Tree Classifier** – Main algorithm used  
- **Jupyter Notebook** – Experimentation and visualization

---

## 📊 Dataset Details

- Features include:
  - Temperature (°C)
  - Voltage (V)
  - Current (A)
  - Vibration (mm/s)
- Label: Equipment Failure (Yes/No)
- Synthetic/Real sensor data simulated
